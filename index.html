jmon / algo

algorithmic music composition and live coding with javascript

An ESM-distrubuted javascript library for generating music from algorithms (musical theory, minimalism, walks, fractals, cellular automata, genetic processes, etc,) emitting JMON, a JSON format for scores, MIDI, and synthesis. Composed pieces play in the browser, render to notation, or stream out via Web MIDI to a DAW.

Explore

  • User guide ten interactive chapters, from JMON basics to live coding
  • Live REPL browser-based live coding surface with audio + Web MIDI
  • JMON schema the format spec (JSON Schema)
  • Source on GitHub code, tests, and issues

Drop-in import

import jm from "https://cdn.jsdelivr.net/gh/jmonlabs/algo@main/src/index.js";

const scale = jm.key("C", "major").scale().generate({ start: 60, length: 8 });
const notes = scale.map((p, i) => ({
  pitch: p, time: i * 0.5, duration: "8n", velocity: 0.7
}));

await jm.play({ tracks: [{ label: "scale", notes }] });
