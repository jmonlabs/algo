jmon / algo

algorithmic music composition with javascript

An ESM-distributed javascript library for generating music from algorithms: musical theory, minimalism, walks, fractals, cellular automata, genetic processes, a rhythm generator, analysis. It makes JMON pieces — a JSON format for scores — and does nothing else with them.

Reading, playing and drawing a piece are three sibling packages, each received by injection rather than imported (Node refuses https:// imports, so that's the only way one of these can depend on another). jmon/studio assembles all four so a call site just says what it does.

The four packages

  • jmon/algo this one — composing: theory, generators, analysis
  • jmon/io the format: MIDI both ways, MusicXML
  • jmon/show playback, live coding, WAV, score engraving
  • jmon/sound sampled instruments for Tone.js

Explore

  • Live REPL browser-based live coding surface with audio + Web MIDI
  • JMON schema the format spec (JSON Schema)
  • Source on GitHub code, tests, and issues

Drop-in import

All four at once, through the facade:

import studio from "https://cdn.jsdelivr.net/gh/jmonlabs/studio@main/src/index.js";
const jm = await studio();

const scale = jm.key("C", "major").scale().generate({ start: 60, length: 8 });
const notes = scale.map((p, i) => ({
  pitch: p, time: i * 0.5, duration: "8n", velocity: 0.7
}));

await jm.play({ tracks: [{ label: "scale", notes }] });

Or just this package, to compose without an audio engine:

import jm from "https://cdn.jsdelivr.net/gh/jmonlabs/algo@main/src/index.js";

const scale = jm.key("C", "major").scale().generate({ start: 60, length: 8 });
